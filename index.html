How cryptic clues work

Every clue is really two clues glued together. One end is a plain definition of the answer. The rest is wordplay that builds the same answer another way: hide it inside other words, swap letters around, add pieces together.

Small signal words tell you which trick is in play: "in" often means hidden, "backwards" means reversed, "cooking" means shuffle the letters. The number in brackets is the answer length. Each basket has three hints if you get stuck.
